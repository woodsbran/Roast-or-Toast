# 1. Introduction

This document captures the primary user stories for Roast or Toast Version 1.0.

Each user story describes a user's goal from their perspective and serves as a guide for product design and development.

---

# 2. Authentication

### US-001

**As a new user, I want to create an account so that my votes, comments, and progress are saved.**

---

### US-002

**As a returning user, I want to log in quickly so I can continue where I left off.**

---

### US-003

**As a user, I want to reset my password if I forget it so I can regain access to my account.**

---

# 3. Gameplay

### US-004

**As a player, I want to immediately see a scenario when I open the app so I can begin playing without unnecessary steps.**

---

### US-005

**As a player, I want to vote Roast or Toast with one tap so gameplay feels fast and simple.**

---

### US-006

**As a player, I want to instantly see how the community voted so I can compare my opinion with everyone else.**

---

### US-007

**As a player, I want to continue directly to another scenario so I can keep playing without interruption.**

---

### US-008

**As a player, I want every scenario to be different so the game stays interesting.**

---

# 4. Community

### US-009

**As a player, I want to read funny comments so I can laugh at other people's reactions.**

---

### US-010

**As a player, I want to leave my own comment so I can join the conversation.**

---

### US-011

**As a player, I want to like comments so I can show appreciation for the funniest responses.**

---

### US-012

**As a player, I want to report inappropriate comments so the community remains enjoyable for everyone.**

---

### US-013

**As a player, I want to submit my own scenarios so I can contribute new content to the game.**

---

# 5. Categories

### US-014

**As a player, I want to browse scenarios by category so I can play topics that interest me most.**

---

### US-015

**As a player, I want to easily switch between categories without losing my place.**

---

# 6. User Profile

### US-016

**As a player, I want to view my profile so I can see my activity and statistics.**

---

### US-017

**As a player, I want to customize my profile picture and username so my account feels personal.**

---

### US-018

**As a player, I want to view my voting history so I can look back at previous decisions.**

---

# 7. Notifications

### US-019

**As a player, I want reminders about new daily scenarios so I remember to come back each day.**

---

### US-020

**As a player, I want to be notified when my submitted scenario is approved so I know it is live.**

---

# 8. Settings

### US-021

**As a player, I want to manage my notification preferences so I only receive alerts I want.**

---

### US-022

**As a player, I want to enable dark mode so the app is comfortable to use at night.**

---

# 9. Moderation

### US-023

**As a moderator, I want to review reported comments so inappropriate content can be removed.**

---

### US-024

**As a moderator, I want to approve submitted scenarios before they become public so the game remains funny, safe, and on-brand.**

---

# 10. Future User Stories

These stories are planned for future releases and are outside the scope of Version 1.

### FUT-001

As a player, I want to create private rooms so I can play with my friends.

---

### FUT-002

As a player, I want to join Party Mode using a QR code so everyone can vote from their own phone.

---

### FUT-003

As a player, I want achievements so I can unlock rewards while playing.

---

### FUT-004

As a player, I want to add friends so I can compare our votes.

---

### FUT-005

As a player, I want weekly challenges so I always have something new to complete.
