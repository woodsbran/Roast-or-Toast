# 1. Purpose

This document defines exactly what Roast or Toast Version 1.0 will include.

The purpose of the MVP is to validate the core gameplay experience with real users as quickly as possible.

The MVP should answer one question:

> **Will people enjoy voting on everyday scenarios enough to return and play again?**

Version 1 is intentionally focused. Features that do not directly improve the core gameplay loop will be postponed until later releases.

---

# 2. MVP Goal

Version 1 should provide a complete and polished experience built around one simple gameplay loop:

Read a scenario

↓

Vote Roast or Toast

↓

See community results

↓

Read funny comments

↓

Continue to the next scenario

If players enjoy this experience and return regularly, the MVP has achieved its purpose.

---

# 3. Success Criteria

The MVP will be considered successful if it demonstrates the following:

- Players understand the game within five seconds.
- Users complete multiple scenarios in a single session.
- Players return on multiple days.
- Users submit their own scenarios.
- Community comments remain active and engaging.
- Players share scenarios with friends.

---

# 4. Target Audience

Primary Audience

- Ages 13+
- Students
- College students
- Young professionals
- Casual gamers
- Social media users

The experience should remain simple enough for anyone to understand immediately.

# 8. Won't Be Included in Version 1

The following features are intentionally postponed.

- Party Mode
- QR Code Rooms
- TV Mode
- AI-generated scenarios
- Creator marketplace
- Paid scenario packs
- Merchandise
- Brand partnerships

These features belong to future versions once the core gameplay has been validated.

---

# 9. Version 1 User Journey

A typical player session should follow this sequence:

Launch App

↓

Read Scenario

↓

Vote Roast or Toast

↓

Watch Results Animation

↓

Read Community Comments

↓

Swipe or Tap Next

↓

Repeat

The average interaction should take less than 30 seconds.

---

# 10. Launch Requirements

Version 1.0 will be considered ready for release when:

- Core gameplay is stable.
- Voting works reliably.
- Results display correctly.
- Comments function properly.
- User accounts are secure.
- The app performs well on iOS and Android.
- Major bugs have been resolved.
- App Store assets have been completed.
- Beta testing feedback has been addressed.

---

# Future Vision

Version 1 is not the final product.

It is the foundation for building the funniest and most engaging social voting game available.

Future releases will introduce additional game modes, social features, creator tools, and party experiences while preserving the simplicity that defines Roast or Toast.
